# 谁是幸运儿 · 悬浮球桌面版

把原「谁是幸运儿」网页抽奖小游戏封装成 Windows 桌面程序。启动后不弹主界面，只在屏幕右下角显示一个可拖动的悬浮球；点击悬浮球打开完整抽奖界面；关闭主界面（点右上角 ✕ 或右上角「✕ 回到悬浮球」按钮）后，界面收起、变回右下角的悬浮球。

## 直接使用

打包好的单文件程序在：

```
D:\dmq.colordev.space\electron\dist\谁是幸运儿-悬浮球.exe
```

双击即可运行，无需安装、无需联网。它是一个自解压便携版，跑起来后：

- 右下角出现圆形悬浮球，位置可拖动，始终显示在最上层。
- 左键单击悬浮球 → 打开「谁是幸运儿」抽奖主界面。
- 关闭主界面（✕ 或「回到悬浮球」）→ 变回右下角悬浮球。
- 悬浮球为纯白圆 + 「幸运儿」字样，按住即可拖动（Pointer 捕获，拖动稳定），单击打开界面。
- **拖动同时支持鼠标与触屏**：触摸拖动时使用触点自身的屏幕坐标，不依赖系统鼠标指针，因此在触摸屏/触控笔记本上同样可以拖到任意位置。悬浮球区域已设 `touch-action: none`，触摸不会被浏览器当成滚动手势而中断。
- 鼠标右键任务栏托盘图标 → 「打开主界面」/「退出」。
- 托盘图标双击也可打开主界面。

## 功能细节

- 主界面与线上网页版完全一致：抽签、滚动速度、音乐、管理员模式均可用。
- 悬浮球可拖动到屏幕任意位置，支持全屏置顶。
- 关闭主界面不会退出程序，只是回到悬浮球；需要真正退出时用托盘菜单「退出」。
- 悬浮球可获取焦点；点击后主界面会可靠地出现在前台（避免被其它窗口遮住“打不开”）。
- 点击与拖动的判定更宽松（移动超过约 7px 才视为拖动），普通点击即可打开，不误触。
- 随时改名单：点左上角「⚙」打开设置，每行一个名字即可编辑，点「保存名单」立即生效并持久化。
- 两个模式各有独立的名单，互不影响，可分别编辑/保存/恢复默认：
  - 趣味模式有自己的一份名单（每行一个名字）。
  - 学号+名字模式有自己的一份名单（每行一个；写成「12 张三」可指定学号，否则自动编号）。
- 模式切换：直接在**主界面顶部**点击「趣味模式 ⇄」按钮，即可在趣味模式和学号+名字模式之间切换并即时保存；原趣味模式及特效/音效不变。
  - 名单行写成「12&nbsp;张三」可为该行指定学号；只写名字则按顺序自动编号。
  - 可配置起始学号、补齐位数、前缀、后缀。
  - 桌面版设置保存到 `%APPDATA%\谁是幸运儿\settings.json`，网页版保存到 localStorage。
- 管理员模式：点左下角「管」直接进入，无需密码。
- 特效管理：点主界面左侧「✦」打开独立界面，可查看/修改/新增/删除特效（绑定到名字）。
  - 每个特效可设置：主题（无/黑底/彩底/葡萄/白底）、背景图、音效、提示文字、是否循环。
  - 支持自定义背景颜色：勾选「自定义背景色」，可自选纯色，或再加一色做渐变。
  - 自定义特效保存在 `settings.json` / localStorage，与内置特效合并生效；「恢复默认」可还原。
- 播报名字：设置里开启「播报抽中的名字」后，抽中某人（或管理员直接指定）时会用系统语音朗读名字；学号+名字模式只朗读名字部分。

## 重新打包

目录结构：

```
electron/
  main.js            主进程（悬浮球/主窗口/托盘、切换逻辑）
  preload.js         contextBridge IPC
  ball.html          悬浮球页面
  webapp/            主界面（从项目根目录复制过来的原网页资源，含“回到悬浮球”按钮）
  build/             icon.png / icon.ico（应用与托盘图标）
  scripts/gen-icon.js 生成 icon 的脚本
  dist/              构建产物（单文件 exe 在此）
```

常用命令（在 `electron` 目录下执行）：

```powershell
npm install          # 安装依赖
npm run genicon      # 重新生成图标
npm start            # 本地调试运行（需清掉 ELECTRON_RUN_AS_NODE）
npm run pack         # 打包单文件便携 exe → dist/谁是幸运儿-悬浮球.exe
```

## 已知说明

- 受当前构建环境限制（Windows 未开启“开发者模式/无符号链接权限”，`winCodeSign` 无法解压），打包时禁用了 `win.signAndEditExecutable`，因此单文件 exe 在资源管理器里的文件图标是 Electron 默认图标。程序运行时的悬浮球、托盘、主窗口图标都是自定义的悬浮球图标，不受影响。
- 打包通过 `extraResources` 把整个网页放进 `resources/webapp`，原始线上部署目录（`D:\dmq.colordev.space` 根目录与 `assets`）未被改动。
